# PROYECTA-IA — Capítulo III: Desarrollo técnico por Objetivos Específicos

Segundo chatbot del **CAPÍTULO III. INGENIERÍA DEL PROYECTO (MARCO PRÁCTICO)**.

## Propósito

Este módulo transforma los Objetivos Específicos en una ruta de trabajo técnico. El eje central es:

> **verbo del objetivo = evidencia de ingeniería que el estudiante debe presentar**

No se admite que un objetivo quede "cumplido" únicamente por haber escrito teoría.

## Funciones principales

- Ingresa Título, Objetivo General y Objetivos Específicos.
- Extrae el verbo principal de cada objetivo.
- Explica el significado metodológico del verbo.
- Propone un subtítulo relacionado con la acción, sin usar "Objetivo Específico N.º...".
- Sugiere subniveles de desarrollo.
- Advierte verbos vagos o expositivos.
- Separa diseño/implementación del Capítulo III respecto de pruebas/evaluación del Capítulo IV.
- Revisa:
  - selección tecnológica;
  - modelo matemático y cálculos;
  - diseño de hardware;
  - simulación y resultados simulados;
  - diseño de software mediante algoritmos/flujogramas;
  - programación y firmware;
  - implementación;
  - diseño mecánico cuando corresponda;
  - chasis/gabinete.
- Permite cargar y previsualizar flujogramas.
- Genera prompts para revisión profunda en ChatGPT.

## Verbos contemplados

Identificar, determinar, seleccionar, elegir, analizar, caracterizar, modelar, diseñar, desarrollar, implementar, construir, integrar, calibrar, ajustar, simular, programar, controlar, monitorear, medir, optimizar, validar, evaluar, verificar, probar, describir, explicar y realizar.

## Regla sobre Capítulo IV

Las pruebas formales, evaluación técnica, análisis estadístico, comparación con criterios de aceptación y conclusiones de desempeño **no se desarrollan aquí**.

En Capítulo III sí puede haber:

- resultados de simulación como parte del diseño;
- valores medidos durante integración/implementación para documentar señales e interfaces;
- calibración o ajuste cuando un Objetivo Específico lo exige.

## Telecomunicaciones

Este módulo solo orienta la organización general. El diseño detallado de redes de telecomunicaciones se trabajará en un chatbot especializado y no se obliga a implementar físicamente la red.
